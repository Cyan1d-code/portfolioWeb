About
 This is a business profile webpage for "Otakuchan Shoppu Global".
 It is made together with Cyan1d in fulfillment for Finals Examination and Project for WebDev 224.

How to run:
- Extract WebDev Balajadia-Decierra.rar to a folder
- Browser Compatibility: Brave Browser, Google Chrome, Opera, Opera GX, Mozilla Firefox, Microsoft Edge
- Open the WebDev.html
- Internet Connection required upon sending inquiries.

Features:
- Parallax Effect for a smooth scrolling experience
- HTML pages combined into one instead of 4 for simpler webpage
- Photos of events that we covered together with local partners namely Purple Passion PH, Krey, Maria, Mc-san Shoppu, and 7utauta/AinyaPrimus.
- Inquiry form powered by Google Forms for submissions.
